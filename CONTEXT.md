# Project Context

Canonical domain terms for this project. Edited via `mars glossary`.

## Language

**Idea**:
A unit of work in the shaping stage — a goal plus optional story/acceptance/technical notes — stored in state.db.ideas; the post-pivot bucket unifies what used to be separate drafts and reflection suggestions.
