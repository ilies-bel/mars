# Bundle release tag is the ADR 0005 semver tag

ADR 0009 (Releases ship one Bundle tarball) describes the GitHub Release as the one 'matching the semver tag' but never cites the source of that tag definition by number. This ADR makes the cross-reference explicit and load-bearing: the 'semver tag' a Bundle release matches is exactly the framework-version tag defined in ADR 0005 (Framework versions are semver git tags on the framework repo) — vMAJOR.MINOR.PATCH on the framework repo, with -rc.N prereleases. There is no second tag scheme. Concretely: the tag mars install/update resolve (ADR 0005), the GitHub Release the Bundle tarball is attached to (ADR 0009), and the string recorded in mars.lock (ADR 0005) are the same semver tag. Why: ADRs are append-only, so the implicit phrase in ADR 0009 cannot be edited in place; a linking ADR is the only way to make the dependency citable without rewriting history. Cost: one extra ADR whose entire purpose is a pointer; readers of ADR 0009 must follow the link rather than seeing the citation inline.
