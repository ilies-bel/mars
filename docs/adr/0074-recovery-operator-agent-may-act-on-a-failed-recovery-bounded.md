# Recovery operator agent may act on a failed recovery, bounded by one pass per arc

Amends ADR-0060, which permitted acting on a failed fix task only via a deliberate human gesture on the grounds that 'a deliberate human action is not an auto-spawn'. Evidence that the ADR-0061 first-principles fallback is insufficient (50 consecutive failed recipe-less fixes) motivates admitting an agent actor: the recovery operator picks up any arc with no automatic move left (no recipe, or the recovery itself failed) and may restart, continue, or supersede it. The human's implicit bound — noticing a loop and stopping — is replaced by an explicit arc-scoped rescue counter permitting exactly one operator pass per arc before escalating to a human. Trade-off: this reopens a narrow, counted path for automatic machinery to act on a fix task, which ADR-0060 closed structurally; the counter must be read only by the operator-spawn path, never by the dispatcher, since consulting it at unblock time is precisely the defect that silently failed 39 origin tasks before they ran.
