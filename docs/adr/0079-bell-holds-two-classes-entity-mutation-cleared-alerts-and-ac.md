# Bell holds two classes: entity-mutation-cleared Alerts and ack-cleared Notices

Context: not everything the operator must see is an arc-rooted Alert (ADR-0054) — some bell items are entity-less facts (e.g. the Steward raised the concurrency limit) with nothing to mutate, so ADR-0048's mutation-only clearing cannot apply to them. Decision: the Bell renders two distinct classes — Alerts (derived, clear only on entity mutation, no ack; ADR-0048/0054 upheld) and Notices (a new durable notices row with an acknowledged_at flag, cleared by an operator 'mars notice ack'). This does NOT reintroduce dismissals for Alerts: a Notice has no entity projection to orphan, so its acknowledged flag IS its own lifecycle state, which is why ack is coherent here and remains forbidden for Alerts. Trade-off: we re-add an ack verb ADR-0048 deleted, but scoped to a class that genuinely needs it and cannot be a projection.
