# Every regular-task failure spawns a fix, even with no recipe; context-exhausted spawns a fix not a task; restart spawns a task

Supersedes ADR-0002 (every failure signature must have a recipe). Uniform failure handling: ANY automatic failure of a regular (kind='task') task spawns exactly one recovery (kind='fix'), regardless of whether a recovery recipe exists for the signature. A recipe-less fix runs the fixer from the failed worktree + transcript instead of a recipe script. The context-exhausted path stops enqueuing a kind='task' blocked follow-up (the old enqueueFollowUpOnce path) and instead spawns a fix that resumes the half-done worktree immediately (leaf, not blocked). The operator Restart gesture remains the only path that spawns a fresh kind='task' from setup. Combined with the amended ADR-0040 (no AUTO edge on a fix; operator may attach one), the failure graph is now uniform: automatic = fix, operator = task. Trade-off: a recipe-less fix is lower-confidence than a recipe-driven one, but a uniform arc and resumed work beat a dead-end 'unknown signature' action-queue row that stranded the worktree.
