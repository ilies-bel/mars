# Retire ADR 0009 (Bundle-only releases) in favour of prebuilt per-OS/arch mars binaries

Supersedes ADR 0009 (Bundle-only releases) and contextually amends ADR 0020 (Bundle release tag = ADR 0005 semver tag). Decision: 'mars' is shipped as a prebuilt single-file executable per OS/arch (initial matrix: darwin arm64, darwin x86_64, linux arm64, linux x86_64) attached to each GitHub Release, with sha256 sidecars. The consumer install path is the curl-pipe-bash bootstrap documented in CLAUDE.md (Installation section), which downloads the matching binary and drops it on PATH. Trade-off accepted: the release workflow takes on a per-OS/arch CI matrix build cost (one job per (os, arch)) in exchange for a zero-dependency prod install — consumers no longer clone the repo, install Bun/Node, or run a wrapper that shells out to tsx. ADR 0009 was the previous answer (ship the bundle, let consumers run it through their own toolchain); this ADR records that the operator-experience cost of that model now outweighs the CI cost saving. Scope of this ADR: the decision only. The actual release workflow rewrite and per-platform build commands stay in PRD 5ed09f38 (in-flight; see UNBLOCK-mars-fd123b9b.md).
