# Releases ship one Bundle tarball, no prebuilt binaries

Each framework release publishes a single asset, mars-bundle-vX.Y.Z.tar.gz, plus a .sha256 sidecar, on the GitHub Release matching the semver tag. The tarball contains only the union of manifest.json owned[] + hybrid[] paths plus manifest.json itself — not the whole repo. Prereleases (-rc.N) get the prerelease flag on the Release but ship identical assets. Why: keeps the release surface honest (what ships is what mars install/update consume), avoids the per-OS/arch matrix of binary builds, and matches ADR 0004's contract that manifest-listed files are the framework's owned domain. Cost: mars install requires a host Bun (no zero-dep bootstrap), and the asset names become a public contract that mars install/update parse.
