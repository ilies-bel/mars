# A Subject closes on a declared terminal Outbox event, not on agent self-report

Focus mode needs a moment where one Subject ends, the agent context is reloaded, and Mars offers the ranked next Subjects. Candidates were agent self-report (the Subject narrates that it is finished) or an operator gesture; both make closure a judgment call, and a chat agent finishes a run after every turn, so 'run ended' cannot mean 'Subject ended'. Decision: a Subject declares a terminal domain event when it opens and closes when that event lands on the Outbox, observed by an ordinary durable-cursor Subscriber (ADR-0030/0031) correlated by entity id — a grilling Subject declares proposal.promoted for its proposal. Closure therefore means the work the Subject existed for actually happened, not that an agent believes it did. Trade-off: Subjects with no terminal event (open-ended questions) never auto-close and depend on the operator's explicit end-Subject action; verb invocations made outside a Worker Session (a human's own terminal) emit no event and so do not close the Subject.
