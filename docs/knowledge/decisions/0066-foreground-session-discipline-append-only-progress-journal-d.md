# Foreground-session discipline: append-only Progress journal, dual live entry with attach-time Handoff, scaffolded advisory hooks (extends ADR-0065)

Context: ADR-0065 made live execution ownership-based: a workflow parks a task in awaiting-human, a human takes the Lease (mars attach), works in the task's worktree in their own Foreground session, and releases (mars release), resuming the pipeline at verify. The discipline layer is missing. A Foreground session has no way to record progress mid-flight — leaseNote is written once at park time and the done-criteria checklist printed by attach is not checkable anywhere. Live entry exists only where a workflow composes awaitHuman, which the scaffolded task-workflow ships commented out, so nothing parks out of the box and there is no way to start work live. Attach surfaces no context about what the background Worker already did, so a take-over session rediscovers instead of continuing. And the install scaffold (templates CLAUDE.md, bundled skills, hooks, statusline) never mentions the live flow at all.

Decision: one discipline layer, three extensions.

1. Progress journal. An append-only per-task journal written via `mars task note <id> "..."`, plus done-criteria check-offs via `mars task check <id> <n>`. Writes funnel through the Arc aggregate (ADR-0052 sole-writer); reads surface in `mars task show`, the UI, and the attach-time Handoff. Chosen over mutating leaseNote (no history, one slot) and over status-only discipline (no mid-flight signal for the operator or for deep reflect).

2. Dual live entry. (a) Park-at-setup: `mars task add --live` runs setup then parks awaiting-human before the code step, so a Foreground session owns the work from minute one while verify and merge still gate the exit. (b) Take-over with Handoff: attaching to a task parked after a code step surfaces the Worker's Completion report, the commits ahead of the integration branch, done-criteria state, and the Progress-journal tail. A Proposal may also be promoted un-sliced into a single live task carrying the PRD, for plan-scale foreground work that progresses under journal discipline.

3. The install scaffold ships the discipline. A live-loop skill; a SessionStart hook that injects the leased task's identity, criteria, and Handoff when a session opens inside its worktree; an advisory Stop hook that warns on dirty worktree or stale journal; a statusline lease segment; and a Live execution section in the scaffolded CLAUDE.md. Hooks advise, never block — the release dirty-worktree refusal remains the only hard gate.

Why this does not reverse ADR-0063: no human attaches to a running agent and Mars still drives no TTY. The Handoff is a state read at attach time, not a stream; park-at-setup means no agent is running while the human holds the Lease.

Trade-offs accepted: a journal table and two verbs widen the schema and CLI surface for advisory data; park-at-setup holds a worktree with no agent running for as long as the human dawdles (mitigated by the existing lease-expiry alert, never auto-kill); advisory hooks can be ignored — drift risk is accepted rather than blocking an operator mid-exploration; Handoff content is derived (Completion report + git log + journal), not a new persisted artifact, so it is legitimately empty for tasks parked before any code step, and nothing may be written inside the worktree itself since release refuses dirty worktrees.
