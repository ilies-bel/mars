# Structured-writes are never a dispatched slice deliverable

Glossary terms and ADRs are decided and written during grill, before a PRD reaches prd-ready, via daemon-routed mars glossary/adr verbs that fast-forward into the integration branch with no task branch. Therefore the slicer must never emit a structured-write-only slice; such a slice is a symptom of a process violation upstream (a PRD promoted with vocabulary work pending), not a case the slicer handles. Consequence: the 'writer' TaskTag and its accommodation path in the implement workflow (skipDiffCheck on tag==='writer', the merge short-circuit, WRITER_SYSTEM_PROMPT/WRITER_FOOTER) are removed as a hard cut, since the task class they existed to serve must not be produced. The no-commits-ahead/has-diff gate then applies uniformly: every slice must land a commit on its own task branch.
