# Live execution is ownership-based worktree leasing (awaiting-human), complementary to ADR-0063's no-attach rule

Context: ADR-0063 retired the tmux backend and ruled out human-attach: the pty Runtime is non-attachable and operators read traces after the fact. A new need emerged from real usage: frontend-impactful work bypasses Mars entirely because the pipeline forces AFK execution — the operator cannot QA and iterate mid-task, so Mars only gets background work. The framework needs a live execution mode without reversing 0063.

Decision: live execution is OWNERSHIP-based, not attach-based. A workflow parks its task in an 'awaiting-human' state carrying a worktree lease; the human takes the lease (mars attach), works in the task's worktree in their OWN interactive session — Mars drives no TTY, streams nothing, attaches to nothing — and releases it (mars release), at which point the pipeline resumes at verify. The phantom watchdog treats parked/leased tasks as alive by design (no managed PID); lease expiry raises a level-triggered action-queue row rather than auto-failing. Workflows opt in per-kind by composing the awaitHuman primitive (e.g. setup → code → awaitHuman → verify → merge), so the same state manager serves fully-AFK, fully-live, and hybrid execution. The existing --preview gate is a special case of this shape.

Why this does not supersede ADR-0063: 0063 rejected attaching a human to a RUNNING agent's terminal and the consumer-machine tmux dependency. Ownership leasing needs neither — the agent is not running while the human holds the lease; the handoff is a state transition, not a stream. Provider-agnostic pty execution (0063) and human leasing are orthogonal axes of the same executor seam.

Trade-offs accepted: a parked task holds its worktree and blocks dependents for as long as the human dawdles (mitigated by lease-expiry alerts, never auto-kill); human work is subject to the same verify gates and dirty-worktree rules as Worker output — release refuses on uncommitted changes rather than silently losing work.
