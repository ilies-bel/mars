# Recovery leaf-node rule is about auto-spawning, not edges per se: no automatic edge may attach to a fix task, but an operator may attach a fix to a fix via a mars command

Amends ADR-0040. The invariant a recovery (kind='fix') task enforces is that NO automatic machinery (fail-fix-handler, exhaustion path, Linker lexical edges, blocker cascade) may spawn work off it or chain it — this is what prevents infinite recovery-of-recovery cascades. It is NOT a blanket ban on the fix ever being an edge endpoint. An explicit operator gesture (a 'mars' CLI verb) MAY create a fix on a recovery task when a human decides the recovery itself needs repair; a deliberate human action is not an auto-spawn. assertNotRecoveryEdge remains the guard for every AUTOMATIC task_blockers writer; the new operator path is a documented bypass, mirroring how spawnRecovery already bypasses it for the one legitimate origin->fix edge. Trade-off: provenance-based enforcement (who/when) is subtler than the old structural ban, but it unblocks the legitimate 'operator repairs a stuck recovery' case without reopening auto-cascade.
