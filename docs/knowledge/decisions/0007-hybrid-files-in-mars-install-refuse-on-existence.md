# Hybrid files in mars install refuse on existence

Context: 'mars install' applies a manifest of framework-shipped paths to a consumer repo. Some paths (settings.json, .gitignore) are 'hybrid' — the consumer may already have written to them. Decision: hybrid files listed in the manifest are written only if absent in the consumer; if present, 'mars install' refuses with a clear backup-and-remove message. No deep merge, no array-concat, no markers, no conflict UI. Why: same spirit as ADR-0004 — prompting, refuse-on-drift, and three-way merge all imply a conflict UI we explicitly don't want. Refusal is honest about the cost and forces the consumer to make the decision explicitly. Cost: ergonomic re-installs are not possible when the consumer has any local change to a hybrid file.
