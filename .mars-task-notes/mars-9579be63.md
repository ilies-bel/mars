## Rationale

The failing error was a TypeScript TS2339 — a test file referenced
`isAutoReflectDisabled` which no longer exists on `auto-reflect-gate.ts`
(renamed to `isMemoryCaptureDisabled`). This class of failure (non-existent
named export referenced in code) is caught precisely by `tsc --noEmit`; no
sharper deterministic check exists because the constraint is a type-level
symbol-existence rule.

The full `npm run typecheck` in the `orchestrator/` directory is the
narrowest correct scope: it covers the entire `orchestrator` package
(where both the source and tests live) while excluding unrelated packages.
